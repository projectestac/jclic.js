Constructor

Parameters

  • nRows (number) — Number of rows to be processed
  • nCols (number) — Number of columns to be processed
  • content (Array.<module:boxes/ActiveBagContent.ActiveBagContent>) — Array with one or more containers of ActiveBoxContent
    objects to be filled with new content.
