# JClic
Player and authoring tool for educational activities

Francesc Busquets\
Generalitat de Catalunya - Departament d'Educació

## Main site
https://projectes.xtec.cat/clic

## Development
- https://projectestac.github.io/jclic (original JClic project, made with Java)
- https://projectestac.github.io/jclic.js (this project)
- https://moodle.org/plugins/mod_jclic (JClic module for Moodle)
- https://github.com/projectestac/jclic-repo (Front-end React Web Components for repositories of JClic activities)
